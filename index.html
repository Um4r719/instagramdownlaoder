FAQ

Frequently asked questions

Do I need an Instagram account?

No. This interface does not ask for an Instagram login. Only URLs accepted by the connected API can be processed.

Can I download private videos?

No. The site should only be used with publicly accessible content and content you have permission to save.

What format is downloaded?

The example API response returns a direct MP4 video URL, which this page uses for preview and download.

Why did my download fail?

The Instagram URL may be invalid, the content may be unavailable, or the external API may have rejected or failed the request.
